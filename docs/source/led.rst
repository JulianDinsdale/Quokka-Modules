LED Module
==========                                                       
QK-02-051

Description
The LED Module provides a bright LED which is turned ‘ON’ by a ‘High’ signal at the connector.  The module may be fitted with a white, red, blue or green LED.  It can be connected to the Kookaberry using a 3 Pin to 3 Pin JST PH cable

Specification
Operating Temperature 	                10 to 50 deg C
Interface	Quokka 3 Pin JST PH 
Pin 1= Signal, Pin2= VCC, Pin 3 = GND
	Voltage				3.3 volts max 
	Current				Typically 6 to 10mA nominal
	LED				3528 (typical)  –white, red, blue or green
	Size				30 x 20 mm



Pinout

Connector - JST PH 3 Pin

	Pin 1 – Signal         On = Hi=3.3 volts (max) 
Off = Low = 0 volts
	Pin 2 – VCC            3.3 volts (max) 

Pin 3 - GND            0 volts



Application

Used in a variety of applications where a visual on/off indication is required.  The module may be used in conjunction with pulse width modulation to vary the light intensity of the LED.



Sample Code

Connect the LED Module to connector P1 on the Kookaberry / Pico Breakout module using a 3 Pin to 3 Pin JST PH cable.  The KookaBlockly script will flash the LED at 0.5 second intervals.
