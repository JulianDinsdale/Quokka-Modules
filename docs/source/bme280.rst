BME280 Environment Sensor

Description
-----------
The Environment Sensor uses the Bosch BME280 sensor to detect air pressure, temperature and humidity.  The module is connected to the Kookaberry via a 4 Pin to 4 Pin JST PH cable (QK-03-023)
When connected to the Kookaberry the module communicates using the standard I2C serial interface, using the integrated I2C MicroPython driver in the Kookaber*-y ,ry firmware.

Interface
	Quokka 4 pin JST PH     
Serial I2C
	I2C Address Is 0x77.  The module has an alternative address of 0x76 when TP1 is connected to TP2.
	A standard library driver is built into the Kooka Firmware which supports both the BME280 and the BMP280 sensors.

Pinout

Connector              	JST PH 4 Pin

	Pin 1 – Signal A - SCL  	On = Hi=3.3 volts (max) 
   	Off = Low = 0 volts
Pin 2 – Signal B - SDA     On = Hi=3.3 volts (max)          
   	Off = Low = 0 volts
Pin 3 – VCC            	3.3 volts (max) 
	Pin 4 – GND           	0 volts

Application

The BME280 Environment Sensor may be used to sample temperature, atmospheric pressure and humidity at sample rates greater than once per second.

Sample Code

Plug the BME280 Environment Sensor into connector P3 on the Kookaberry using a 4 pin to 4 Pin JST PH cable (QK-03-023) ie P3A (GP13), P3B (GP12)
